## 1.12.0 对齐内容

- 字体：`RenderOptions::monospace` 和 CLI `--monospace members,attributes,files,messages` 分别控制 Class 成员、ER 属性、TreeView 文件名和 Sequence 消息；测量与 SVG 字体同步，作者显式字体继续优先。选项进入渲染缓存身份，Rust Zebra 适配器同样接收；现有 C ABI v2 保持其既有选项集合。
- 填色：按上游 sRGB 亮度、透明度、颜色名称及 hex/rgb/hsl 解析选择文字对比色；显式文字颜色优先。边线位于填色内时使用对比色，跨填色边界时增加背景描边；空心标记保留底色。覆盖 Flowchart、Swimlane、Agentflow、State、ER、C4、Usecase、Class、Requirement、Block、Treemap、Venn 和 Sequence 的对应部分。网页输出保留 CSS 变量，原生路径输出具体颜色。
- Block：并行与反向边保留各自标签；避让相邻标签、节点、复合标题和箭头。只有确实减少重叠且不超过 `maxWidth` 时扩展行列间距，保留能够直连的路径。
- Sequence：在 `maxWidth` 预算内先分配可用间距再换行；支持消息等宽测量、嵌套 rect/box 填色及人物名称着色。跨生命线的标签底板和越过 box 的自连线继续按上游主题处理。
- Treemap：保留极细和零面积的正值节点，有限尺寸夹到父区域；拥挤树使用统一较小间距，作者 padding 优先。小分组采用短标题或取消标题并保留完整祖先 tooltip；字体按作者尺寸适配，不用缩小作者字体来掩盖空间不足；小矩形圆角受短边限制。
- 解析与错误：各语法接受以 `title` 开头的合法名称；Radar 与 Venn 关键词不切断较长名称；Sankey 忽略每行边缘空白并映回原始位置。EOF 错误指向最后可见内容之后，实体占位符保留 UTF-16 源列映射。跨组连线按上游继承父方向。
- URL：保留安全地址里的百分号编码，同时检查解码后的 scheme/网络路径，不能靠清洗或编码隐藏被禁链接。
- 发布参照：默认 info 为 `Pele v1.12.0`；库、CLI、清单、生成器、对照工具、许可证及画廊固定到新提交。原有 167 个样本的输入和顺序未变，旧版 fixture 与测量证据保留。

首轮回归修复了 Usecase actor 图形填色误影响文字、Sankey 旧预处理预期和标签参照源码指纹。原始 Agentflow 3,000 层链用例也暴露新增祖先集合扫描的开销；CPU 采样定位后，在没有作者方向可清除时直接返回。完整输入、输出和原 3,000 ms 门槛保持不变；独立 debug 门槛复验为约 248 ms。此读数仅为原测试诊断，不是性能基准或 2× 目标证据。

上游 Zoom 和网站文档/示例改动保留在源码差异记录中；未新增浏览器宿主实现，也不把其测试算作 Rust 已通过。运行时继续为纯 Rust，不依赖 Node、浏览器或外部布局程序。

## 默认数学排版


按用户要求，**删除 math 回调 API，默认使用 RaTeX 0.1.15**。运行时不依赖 JS、Node、浏览器或外部布局程序。RaTeX 解析和排版，内置 KaTeX 字体生成 SVG 字形路径；普通公式无需宿主字体或 CSS。

`$$…$$` 标签公式启用于 flowchart、sequence、state、class、ER、mindmap、kanban、block、requirement、usecase、swimlane 共 11 类。公式尺寸参与换行、节点尺寸和行距；原生输出采用当前宿主主题的具体颜色，保留作者显式公式颜色。无效 TeX、不可用字形回退为源文本；原生禁图策略同样作用于公式。标题、class 成员和其他图类型保持文字行为。

这属于用户明确指定的宿主 API 差异：**Pele 的回调行为测试仍保留在清单中且未映射；默认 RaTeX 的补充测试不冒充其 1:1 移植。** 既有数学专项为 2 项单元测试、6 项集成测试，覆盖全部 11 类、两种颜色模式、尺寸、有效 XML、作者颜色与透明度、错误回退及原生图像限制。

## Zebra 主题与宿主契约


复用 Zebra 当前主题，不要求用户另行维护 JSON 主题文件。现有 camelCase palette JSON 是既有 Swift → Rust ABI 的传输格式。网页模式保留 Pele CSS；原生模式解析具体颜色，不依赖 `var()`、`color-mix()` 或媒体查询。作者样式优先，透明画布只省略整幅背景，内部对比度继续使用宿主背景色。

默认全部 33 类启用。`MermaidPalette`、light/dark、fontSize、画布和颜色模式分别传入，颜色改变不改变几何。Zebra `target_width` 校验但不参与布局，保留 `renderingDependsOnTargetWidth = false`；普通调用的 `max_width` 独立生效。原生策略关闭链接与图像外部引用。

现有主题矩阵、适配与 C ABI v2 单元测试通过；完整原生 App/xcframework 替换、App 内主题切换与缓存验收尚未执行。主题契约和字段回退见 [ZEBRA-THEME-COMPATIBILITY.md](ZEBRA-THEME-COMPATIBILITY.md)，C 头文件见 [zebra_mermaid.h](../crates/zebra-mermaid-ffi/include/zebra_mermaid.h)。

- `%%{init}%%` JSON 深度上限为 200；与 JS 依赖栈耗尽的失败边界存在差异。Zebra 源长上限沿宿主 262,144 个 UTF-16 单位，输出上限为 4 MiB UTF-8 字节。
- Gantt 对照固定 UTC；当前提供固定偏移，完整 DST 策略未完成。fdlibm/V8 对照保留，但平台 C `pow` 的舍入仍不保证跨平台一致。
