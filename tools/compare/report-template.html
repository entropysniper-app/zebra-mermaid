  • Sample 由上游 website/src/lib/examples.ts 的 sampleGroups() 原函数选择，未根据渲染结果删改输入。每份源码与每个输出都有 SHA-256 记录。

  • Mermaid 的 HTML 标签按照其推荐的 DOM 插入方式呈现，再通过 XMLSerializer 导出可独立打开的 SVG；其原始返回字符串也单独保留。此步骤只处理导出格式。
  • 缩略图会各自缩放以适应单元格，不代表三份输出具有相同尺寸。原始 viewBox / 视口尺寸显示在图下，可通过“原始尺寸”查看。
