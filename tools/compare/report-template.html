Reading the comparison
  • Samples come from the original sampleGroups() function in website/src/lib/examples.ts. No input is removed or changed based on its result. Sources and outputs have SHA-256 records.
  • The gallery uses the Playground dark appearance, system fonts, and 6 px corner radius. Rust/Pele share browser font measurements and site icons, with independent parsing, layout, and SVG generation. Mermaid uses theme: dark. Time is fixed to 2026-10-19 00:00 UTC; authored front matter remains active.
  • Mermaid HTML labels are inserted into the DOM and exported with XMLSerializer for standalone viewing. Original returned strings are also retained. This step only changes the export format.
  • Previews scale to fit each cell. Actual viewBox or viewport dimensions appear below each image; select Actual size to inspect the original scale.
  • Rust/Pele use the Playground site icon resolver; Mermaid has no extra icon packs. External requests are recorded. Sample rendering does not replace full original-test acceptance.
