# Skipped state specs

Ported from Mermaid mermaid@12.1.0. Generated by `scripts/sync-specs.mjs`.

## Skipped tests

- `stateDb.spec.js`: "sanitizes on the description". Expects DOMPurify to have removed a script element from the stored description. Pele stores text as written and escapes it when writing SVG.
- `stateDb.spec.js`: "should have functions used in flow JISON as own property". Checks that StateDB methods are own properties, a requirement of the Jison runtime. Pele has no Jison runtime.
- `stateDiagram-v2.spec.js`: "should handle note statements". Its snapshot expects `<br/>` in the note text to be stored as `<br>`, which is DOMPurify's serialization. Pele stores text as written; both spellings break the line when drawn.
- `stateDiagram-v2.spec.js`: "should handle multiline notes with different line breaks". Its snapshot expects every spelling of `<br>` in the note text to be stored as `<br>`, which is DOMPurify's serialization. Pele stores text as written; all of them break the line when drawn.

- `stateRenderer-v3-unified.spec.js`: Tests Mermaid's DOM renderer wiring and its HTML tooltip element.
